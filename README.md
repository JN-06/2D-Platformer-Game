COS10009 Introduction to Programming
Custom Program Plan

Project Summary:
Developed a 2D platformer game in C using the Raylib graphics library, featuring multiple levels, traps, collision detection, level progression, save/load functionality, and game-over and victory states. Implemented character movement and jumping animations, sound effects, delayed trap triggers, and level reset mechanics. Applied modular programming and struct-based abstraction to improve code organization, maintainability, debugging, and future feature development.
