# IntrotoP

The program is a 2D platformer game written in the C programming language using the Raylib graphics library. It is inspired by the challenging game “I Wanna Be The Guy”, known for its unexpected traps and challenging gameplay. In my program, players can take control of a character who must navigate through a series of levels filled with traps and difficult obstacles to reach the finish point. If the character touches a trap, the game resets to the start of the current level by pressing ‘R’, encouraging players to learn from trial and error.
One of the key features of the game is a save and load feature, which allows players to continue from the last completed level. The game also includes a game-over screen and a victory screen, which depend on the player’s outcome. Additional features include smooth character animations for movement and jumping, sound effects for actions like jumping and dying, and traps that are triggered with a slight delay when the player gets close, adding surprise and difficulty to the gameplay.
From a design perspective, the program is structured using modular design principles. Different components of the game such as map loading, level progression, collision detection and so on, are organized into separate functions, making the code more readable and easier to maintain. The program also uses abstraction through structs to represent key game entities such as the player, encapsulating the properties and behaviors. This modular and abstracted design facilitates debugging, testing and future feature expansion.
Overall, the program demonstrates strong coding practices, a clear and organized design structure, and interactive gameplay elements, resulting in an engaging and well-crafted software product.
